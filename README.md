# Proiect de Atestat - Bază de Date Oracle APEX

Proiect de atestat la Informatică axat pe proiectarea relațională, normalizarea și implementarea unei baze de date pentru gestiunea unei universități.

## Tehnologii Utilizate
* **Platformă:** Oracle APEX (Application Express) / SQL Workshop
* **Limbaj:** SQL (DDL & DML)
* **Modelare:** Diagrame ERD (Entity-Relationship Diagram), Formele Normale 1FN, 2FN, 3FN

## Structura Proiectului
* **Entități și Tabele:** `MATERII`, `PROFESORI`, `NOTE`
* **Normalizare:** Rezolvarea relațiilor Many-to-Many prin crearea entităților de legătură
* **Interogări SQL:** Comenzi de creare a tabelelor, populare cu date, filtrare (`WHERE`), sortare (`ORDER BY`) și operații aritmetice pe coloane
